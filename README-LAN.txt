วิธีใช้โหมดหลายเครื่อง (LAN) — Robot Arena
==========================================

สิ่งที่ต้องมี
  - เครื่องควบคุม (เครื่องที่รันเซิร์ฟเวอร์) ติดตั้ง Node.js แล้ว (ดาวน์โหลดที่ nodejs.org เลือก LTS)
  - ทุกเครื่องอยู่ในเครือข่ายเดียวกัน (เราเตอร์เดียวกัน / ไวไฟเดียวกัน / ฮอตสปอตเดียวกัน)
  - ไม่ต้องใช้อินเทอร์เน็ต และไม่ต้อง npm install

เริ่มใช้งาน
  1) ดับเบิลคลิก start-server.bat   (หรือเปิด Command Prompt ในโฟลเดอร์นี้แล้วพิมพ์ node server.js)
     - ครั้งแรก Windows จะถามเรื่อง Firewall ให้กด "Allow access" และติ๊ก "Private networks"
  2) หน้าต่างสีดำจะแสดงที่อยู่ เช่น
        เครื่องนี้ (หน้าควบคุม):      http://localhost:3000/
        เครื่องอื่น / OBS (โปรเจกเตอร์): http://192.168.1.25:3000/display.html
  3) เครื่องควบคุม: เปิดเบราว์เซอร์ไปที่ http://localhost:3000/
     (ต้องเปิดจากที่อยู่นี้ ห้ามดับเบิลคลิกไฟล์ index.html โดยตรง ไม่เช่นนั้นจะไม่ส่งข้ามเครื่อง)
  4) เครื่องอื่น: เปิดเบราว์เซอร์ไปที่ที่อยู่ display.html ที่ขึ้นในหน้าต่างสีดำ
     กดเต็มจอด้วย F11 และคลิกที่หน้าจอ 1 ครั้งเพื่อให้เสียงเล่นได้
  5) ดูที่แถบล่างของหน้าควบคุม จะขึ้น "LAN ONLINE • จอที่เชื่อมต่อ N" เมื่อเชื่อมต่อสำเร็จ

ใช้กับ OBS
  - เพิ่ม Source ชนิด "Browser" ใส่ URL เป็น http://IP-เครื่องควบคุม:3000/display.html
  - กำหนดความกว้าง 1920 ความสูง 1080

ข้อควรรู้
  - ถ้าเครื่องควบคุมมีหลายการ์ดเครือข่าย จะมีหลายที่อยู่ ให้เลือกอันที่ตัวเลขช่วงเดียวกับเครื่องอื่น
  - เปิดหน้าควบคุม (index.html) บนเครื่องเดียวเท่านั้น
  - ใครก็ตามที่อยู่ในเครือข่ายเดียวกันและรู้ที่อยู่ สามารถเปิดหน้าควบคุมได้ ควรใช้เครือข่ายที่ไว้ใจได้
  - เปลี่ยนพอร์ต (ถ้า 3000 ถูกใช้แล้ว): ใน Command Prompt พิมพ์  set PORT=3001  แล้วค่อย node server.js
